# Эмулятор командной оболочки

Учебный проект по дисциплине «Конфигурационное управление». Программа имитирует работу в командной строке UNIX-подобной ОС и работает с виртуальной файловой системой (VFS).

VFS загружается из папки на диске в память при запуске. Команды работают только с копией в памяти: настоящие файлы и папки во время работы не изменяются. Исключение составляет служебная команда `vfs-init`.

## Возможности

Приложение имеет графическое окно на Tkinter. Заголовок окна содержит имя VFS: `Эмулятор - [deep]`. Приглашение показывает имя VFS и текущую папку: `deep:/home/user$`.

Поддерживаются параметры командной строки:

- `--vfs ПУТЬ` — путь к папке, из которой загружается VFS;
- `--script ПУТЬ` — путь к стартовому скрипту;
- `--config ПУТЬ` — путь к конфигурационному файлу XML.

Пути к VFS и к скрипту можно задать и в XML-файле:

```xml
<config>
    <vfs_path>vfs_samples/minimal</vfs_path>
    <startup_script>scripts/start_ok.txt</startup_script>
</config>
```

Значения из командной строки имеют приоритет над значениями из файла. Если путь к VFS не задан, создаётся пустая VFS по умолчанию. При запуске в окне выводятся значения всех параметров.

Стартовый скрипт выполняет команды по очереди и показывает ввод и вывод. Ошибочные строки пропускаются с сообщением и номером строки. Строки, начинающиеся с `#`, считаются комментариями.

Перед разбором команды раскрываются переменные окружения реальной ОС, например `$USERPROFILE`. Сообщения об ошибках выводятся красным цветом, работа после ошибки продолжается.

## Команды

| Команда | Назначение |
|---|---|
| `ls [-l] [путь]` | Показывает содержимое папки или имя файла. С `-l` выводит тип и размер. |
| `cd [путь]` | Переходит в папку; без аргумента переходит в корень VFS. |
| `pwd` | Выводит путь к текущей папке. |
| `cat файл [файл ...]` | Выводит содержимое одного или нескольких файлов. |
| `rm [-r] [-f] путь [путь ...]` | Удаляет файлы только в памяти VFS. С `-r` удаляет папки, с `-f` не сообщает об отсутствии файла. |
| `exit` | Закрывает окно эмулятора. |
| `vfs-init` | Заменяет VFS на пустую и очищает папку-источник на диске. Перед очисткой запрашивает подтверждение. |
| `vfs-info` | Выводит имя VFS, путь к источнику и дерево содержимого. |

Пути могут быть абсолютными, например `/home/user`, или относительными, например `docs`. Поддерживаются `.` и `..`.

## Основные функции

`parse()` раскрывает переменные окружения и делит строку на слова. `execute()` находит команду в таблице `COMMANDS` и выполняет её. `cmd_ls()`, `cmd_cd()`, `cmd_pwd()`, `cmd_cat()`, `cmd_rm()`, `cmd_exit()`, `cmd_vfs_init()` и `cmd_vfs_info()` реализуют команды эмулятора.

`VFS.load()` копирует папку с диска в словарь в памяти. `VFS.resolve()` находит файл или папку по пути, `VFS.remove()` удаляет запись из словаря, `VFS.init_default()` заменяет VFS на пустую.

`load_settings()` объединяет параметры командной строки и XML-файла. `run_line()` выполняет одну команду и выводит результат в окно, `run_script()` выполняет стартовый скрипт.

`rm` удаляет запись только из словаря в памяти, поэтому удалённый файл остаётся на настоящем диске.

## Структура проекта

```
main.py              точка входа
config.py            параметры командной строки и XML
gui.py               окно эмулятора
commands.py          разбор строки и команды
vfs.py               виртуальная файловая система
scripts/*.bat        сценарии запуска и проверки
scripts/*.txt        стартовые скрипты эмулятора
scripts/*.xml        примеры конфигурации
vfs_samples/         тестовые VFS, создаются скриптом make_vfs.bat
```

## Требования

Нужен Python 3 

## Запуск

Интерактивный режим без параметров:

```
python main.py
```

С тестовой VFS и стартовым скриптом:

```
scripts\make_vfs.bat
python main.py --vfs vfs_samples/deep --script scripts/start_stage4.txt
```

С параметрами из конфигурационного файла:

```
python main.py --config scripts/config.xml
```

## Проверка

Папка `scripts` содержит стартовые скрипты с командами и ошибками. Они запускаются через `.bat`-файлы из корня проекта:

- `make_vfs.bat` — создаёт тестовые VFS: `minimal`, `files`, `deep`;
- `test_cli.bat` — параметры командной строки;
- `test_config.bat` — параметры из XML-файла;
- `test_priority.bat` — приоритет командной строки над файлом;
- `start_errors.bat` — ошибки конфигурации и стартового скрипта;
- `start_vfs.bat` — три варианта VFS и ошибки загрузки;
- `start_stage3.bat` — команды `vfs-info` и `vfs-init`;
- `start_stage4.bat` — команды `ls`, `cd`, `pwd`, `cat`;
- `start_stage5.bat` — команда `rm`.

## Примеры

```
deep:/$ ls
etc/  home/  readme.txt
deep:/$ cd home/user
deep:/home/user$ ls -l
d        -  docs/
-       10  notes.txt
deep:/home/user$ cat notes.txt
my notes
deep:/home/user$ rm notes.txt
deep:/home/user$ ls
docs/
deep:/home/user$ cat notes.txt
Error: cat: notes.txt: No such file or directory
```

После закрытия программы файл `notes.txt` остаётся на диске, потому что `rm` меняет только VFS, находящуюся в памяти.
